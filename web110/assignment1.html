The Internet Fundamentals activity helped me to understand the basic concepts behind the Internet and how different technologies work together to allow people to communicate and access information online. I learned that the Internet is a network of computers and devices that are connected and communicate with each other using protocols. I learned more about how a person visiting a webpage causes web browsers, servers, websites and Internet connections to work together. Knowing how the Internet works will help me to better understand what happens behind the scenes when I create and publish a website, so this knowledge will be useful in my future web design work. The activity on GitHub and Git repository taught me about version control and why it is important for software and web development in general. I learned that a repository is a place where you can store files for a project and keep track of changes made to those files. This allows to track progress, save previous versions and collaborate with other people. I also learned how to use GitHub to share projects with instructors, coworkers or other developers. I can use this knowledge for future school projects and professional web design as having organized versions of my work can help prevent lost changes and make collaboration easier. Creating and organizing my web design files helped me understand how a project can be structured within a repository. I discovered that there are different files for different purposes, like a README file which contains information about a project and HTML files which are used for webpage content. Sorting files into folders also makes a project easier to understand and maintain as it grows. I can apply this concept to future websites and programming projects by keeping related files together in an organized manner and using consistent file and folder names. This will make my projects easier to navigate, update, and review for me and others. All in all, these activities have broadened my horizons on the Internet and tools used in modern web design. I learned that web design isn't only about writing code for web pages. I am able to learn more about the fundamentals of the Internet, use version control, and organize files in a project. These are all important skills I can work on throughout this course and bring to future educational and professional projects.
