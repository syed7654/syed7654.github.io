Networking Protocols and the Internet Protocol Suite The Internet Reference Models and Internet Protocols activities helped me understand how different networking protocols work together to allow devices to communicate. I learned that the Internet protocol suite is organized into four layers: Link, Internet, Transport, and Application. Each layer has a specific responsibility, with protocols such as IP handling addressing and routing, TCP providing reliable communication, and HTTP supporting web services. I also learned that protocols work together as a stack rather than operating independently. I can apply this knowledge to my own current or future environment by better understanding what is happening when I access websites, send information, or connect devices to a network. This knowledge will also help me troubleshoot connectivity problems by identifying which part of the communication process may be causing an issue. Domain Name System (DNS) The Internet Domain Name System activity taught me how DNS makes the Internet easier to use by translating human-readable domain names into numerical IP addresses. I learned that DNS uses a hierarchical structure containing domains, subdomains, and top-level domains, and that DNS servers are responsible for resolving names to the appropriate IP addresses. This showed me why I can enter a website name into a browser instead of having to remember a numerical IP address for every website. I can apply this concept in my own environment when troubleshooting Internet connectivity or determining whether a problem is related to DNS or the network connection itself. Understanding DNS will also be useful in future IT work because websites, servers, and other network resources commonly depend on name resolution. IP Addressing and Network Connectivity The Review IP Address Settings for Your Local Network and Verify Internet Connectivity activities helped me understand how devices identify themselves and communicate on a network. I learned about IP addresses, default gateways, and the difference between local and remote connectivity. I also learned how tools such as ipconfig, ping, and tracert can provide useful information about a network connection. These concepts can be applied to my own current or future environment when diagnosing problems such as a device being unable to access another computer or the Internet. Instead of assuming that an Internet connection is completely broken, I can use network information to determine whether the problem involves the local device, gateway, routing, or a remote destination. Network Devices and Home Networking The Research and Identify the Necessary Components Required to Set Up a Home Network activity helped me understand the different devices involved in creating a functional network. I learned that devices such as network interface controllers, switches, routers, modems, wireless access points, and firewalls each have different roles. A router can connect different networks, while a switch connects devices within a network, and a wireless access point allows Wi-Fi devices to connect to a network. I can apply this knowledge when setting up or troubleshooting a home network in the future. It will also help me make better decisions when selecting networking equipment because I will understand what function each component provides and how the components work together.
