The Internet Services activity helped me understand how Internet-based services allow people to communicate, access information, and share resources across networks. I learned that many services rely on Internet protocols to transfer information between computers and users. Understanding how these services work is important because the Internet is used for communication, education, business, entertainment, and many other purposes. I can apply this knowledge in my current or future environment by making more informed decisions about which Internet services are appropriate for different tasks. Understanding the purpose of different services can also help me communicate more effectively and troubleshoot basic Internet-related problems. The VoIP / Messaging activity focused on Internet-based communication and collaboration. I learned that Voice over Internet Protocol (VoIP) allows voice communications and multimedia sessions to be transmitted over Internet Protocol networks instead of traditional telephone networks. VoIP services can operate through computers, smartphones, and other Internet-connected devices using Wi-Fi or cellular networks. I also learned that Internet collaboration tools can support communication through voice, messaging, and video. I can apply this knowledge in a future workplace by using communication platforms to collaborate with coworkers, attend virtual meetings, communicate with clients, and work with people who are in different locations. These tools can make communication more flexible and support remote work. The FTP activity helped me learn about the File Transfer Protocol and how files can be transferred between computers on a network. I learned that FTP uses a client-server model and has separate control and data connections. I also learned that traditional FTP can use usernames and passwords without encryption, which creates security concerns. Secure alternatives such as FTPS and SFTP can provide better protection for transferred information, although SFTP is technically different from FTP. I can apply this knowledge in a current or future work environment when transferring files between computers or servers. Understanding FTP and secure file-transfer methods will help me recognize when file transfers require additional security and choose appropriate methods for protecting information.
