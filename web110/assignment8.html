Internet Safety The LearnFree: Internet Safety activity helped me understand the importance of protecting personal information while using the Internet. I learned that online security involves more than simply having antivirus software; it also requires recognizing suspicious links, protecting passwords, being careful about what information is shared, and understanding common threats such as phishing and malware. I learned that attackers often use social engineering to make users voluntarily provide information or download malicious software. I can apply this knowledge to my current and future environment by being more careful with emails, websites, downloads, and requests for personal information. These habits can help reduce the risk of having my accounts or personal information compromised. Internet Security The TutorialsPoint: Internet Security activity taught me about different technologies and practices used to protect information and computer systems. I learned about encryption, authentication, firewalls, antivirus software, and other security measures. Encryption protects information by converting readable data into ciphertext, while authentication helps verify a user's identity. I also learned that firewalls can control network traffic and block potentially dangerous connections. I can apply these concepts in a future workplace by understanding why organizations use multiple layers of security instead of relying on a single protection method. This knowledge will help me make safer decisions when using computers and networks. Web Browser Safety The Practice Web Browser Safety activity helped me understand how browser settings can affect privacy and security. I learned that browsers store information such as cookies, browsing history, cached data, saved passwords, and autofill information. I also learned that keeping browsers and add-ons updated is important because updates can address security vulnerabilities. Private or incognito browsing can prevent certain information from being stored locally, although it does not make a user completely anonymous online. I can apply this knowledge by maintaining safer browser settings on my personal devices and being more aware of what information my browser stores. Password Managers and Multi-Factor Authentication The Research Password Managers and Multi-Factor Authentication activity taught me how password managers and MFA can strengthen account security. I learned that a password manager can securely organize passwords and make it easier to use unique passwords for different accounts. MFA provides additional protection by requiring more than one type of authentication, such as something I know and something I have. I can apply this knowledge to my current and future accounts by using stronger, unique passwords and enabling MFA whenever it is available. These practices can make it much more difficult for someone to gain unauthorized access even if one password is compromised.
